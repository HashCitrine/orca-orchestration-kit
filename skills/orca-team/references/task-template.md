# Task 명세
- 목표와 대상:
- 산출물:
- 수정 가능한 범위와 소유권:
- 제약 및 의존성:
- 검증 명령/관찰 가능한 완료 기준:
- 보고: 짧은 결론, 변경, 테스트 결과와 검증한 revision(미커밋 변경 포함 여부), 차단 사항, 산출물의 절대 경로와 통합에 필요한 커밋/변경 정보, 실제 모델(확인 불가하면 미확인). 긴 로그는 파일로 보존하고 근거 위치만 보고한다. 임시 경로는 임시임을 표시하고 조정자가 정리 전에 영구 보존할 수 있게 한다.
- 조정자 체크포인트는 수정하지 않는다. 기록에 필요한 결과와 근거는 보고로 전달한다.
- 하위 작업자 생성 금지. 추가 분배는 조정자에게 요청한다. Orca preamble의 ask/heartbeat/worker_done 절차 준수.
- 결과 전달과 worker_done 후 턴을 종료한다. 세션 회수와 임시 워크트리 정리는 조정자가 결과 보존을 확인한 뒤 수행한다. 자기 세션이나 워크트리를 직접 삭제하지 않는다.
